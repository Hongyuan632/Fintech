# 模型卡：信用卡客户下月违约概率模型（v1）

> 仅供课程学习与演示。不得用于真实的授信决策。

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 模型 | 逻辑回归（L2 正则，C = 0.1），不另做概率校准 |
| 输出 | 客户下月违约概率（PD），以及按阈值划分的三档建议 |
| 文件 | `models/credit_risk_model.joblib`（含特征工程与预处理）；`models/policy.json`（阈值与模型哈希）；`models/model_meta.json` |
| 训练数据 | UCI Default of Credit Card Clients（编号 350），训练集 21,000 人，分层划分，种子 42 |
| 评分时点 | 2005 年 9 月账单周期结束；只使用 4–9 月的记录 |
| 输入字段（22 个） | `LIMIT_BAL`、`EDUCATION`、`MARRIAGE`、`AGE`、`PAY_0`、`PAY_2`–`PAY_6`、`BILL_AMT1`–`6`、`PAY_AMT1`–`6` |
| 不使用的字段 | `ID`、`SEX`（性别只用于审计；测试验证改动它不影响预测） |
| 派生特征（11 个） | 近六个月逾期月份数、最大逾期月数、最近一月是否逾期、平均实还金额、实还为 0 的月份数、两个还款比例、两个额度使用率、账单 ≤ 0 指示、账单变化趋势 |
| 环境 | Python 3.11，scikit-learn 1.9.1，pandas 3.1.1，numpy 2.4.6 |

## 策略

| 概率区间 | 风险等级 | 演示动作 |
| --- | --- | --- |
| p < 0.15 | 低 | 模拟通过 |
| 0.15 ≤ p < 0.40 | 中 | 进入人工复核队列（最终结果不可观察） |
| p ≥ 0.40 | 高 | 模拟暂缓授信 |

**选择理由。** 情景约束为“复核率 ≤ 30%、通过组违约率 ≤ 10%”，在计算阈值指标之前写定。验证集上比较了 (0.10, 0.30)、(0.15, 0.40)、(0.20, 0.50) 三组候选，只有 (0.15, 0.40) 同时满足两项约束。这些阈值是教学情景，不代表任何机构的风险偏好。

**模型选择理由。** 验证集上随机森林的 ROC-AUC 比逻辑回归高 0.005，但差值的 95% bootstrap 区间包含 0，按预先声明的规则选更易解释的逻辑回归。三种校准方式的 Brier 相差不足 0.0001，按事后补充的平局规则选最简单的未校准版本（保序回归会产生离散台阶和 PD = 0）。详见 `model_report.md` 第 4 节。

## 测试集表现

测试集 4,500 人，违约 995 人（22.11%），在模型和阈值锁定后评估一次。

| 指标 | 数值 | 95% bootstrap 区间 |
| --- | --- | --- |
| ROC-AUC | 0.776 | [0.759, 0.793] |
| KS | 0.425 | — |
| AP（PR-AUC 梯形积分 0.545） | 0.546 | [0.514, 0.580] |
| Brier（基准 0.172） | 0.136 | [0.129, 0.143] |
| ECE（十分位分箱） | 0.015 | — |

| 档位 | 人数占比 | 实际违约率 |
| --- | --- | --- |
| 模拟通过 | 55.0% | 9.7% |
| 人工复核 | 30.4% | 25.1% |
| 暂缓授信 | 14.7% | 62.4% |

以 PD ≥ 0.40 为预测正类：Precision 0.624，Recall 0.414，F1 0.498；误拦 248 名未违约客户（误拦率 7.1%），遗漏 583 名违约客户，其中 240 名被直接通过（漏放率 24.1%），343 名进入复核。

**校准。** 前八个十分位的预测概率与实际违约率相差不超过 2 个百分点；第九分位低估约 6 个百分点，最高分位高估约 3.5 个百分点。校准曲线见 `figures/fig15_test_calibration_tiers.png`。

| 21–29 岁 | 1,457 | 22.0% | 55.2% | 7.9% | 22.1% |

- 模型不使用性别，但男性通过率低约 4 个百分点，验证集上方向一致。其他字段间接反映了群体差异。

## 适用边界与已知限制

1. **人群与时间。** 样本是 2005 年台湾地区已持卡的客户。模型没有在其他地区、其他时期或新申请客户上验证过。随机留出只能说明同一时期内的区分能力，不能说明模型随时间是否稳定。
2. **只预测是否违约。** 数据没有违约损失率、风险敞口、回收金额，也没有人工复核的结果。因此不能据此估算预期损失或利润，也不能评估“人工复核”这一环节的效果。
3. **各档人数会随样本波动。** 按固定概率阈值分档，验证集复核率 29.96%，测试集 30.4%，略超 30% 的容量。容量是硬约束时，应按风险排序取固定名额送审，或给容量留余量。
4. **数据编码问题。** `PAY_2`–`PAY_6` 几乎没有编码 1，与 `PAY_0` 不一致；`PAY_*` 的 −2 和 0、`EDUCATION` 的 0/5/6、`MARRIAGE` 的 0 在原说明中没有定义。模型保留原值或合并为“其他”。“其他教育程度”一组的系数为 −0.60，对应该组异常低的违约率（训练集 7.1%），可能是数据整理造成的，不应解读为教育程度的影响。
5. **系数不能逐个解读。** 还款状态的独热列与派生的逾期特征高度共线，单个系数的正负没有独立含义。解释单笔预测时应按字段分组看贡献。
6. **相关不是因果。** 额度低的客户违约率高，不说明降低额度会导致违约，也不说明提高额度会减少违约。
7. **一条选择规则是事后补充的。** 校准方式的平局规则在看到验证集结果后加入（见上）。模型族的选择规则和阈值的约束都是事先写定的。
